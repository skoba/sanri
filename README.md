# 診療報酬のLeanモデル

医科診療報酬点数表の区分・点数・算定条件・包括・併算定制限を、Leanで段階的に記述するプロジェクトです。ユーザーから提示された本文を仕様の根拠として、**外来を優先**して実装しています。

## ビルドと検証

```sh
lake build
```

[Sanri.lean](./Sanri.lean) から各モジュールを読み込みます。算定例、境界値・除外条件の検証、一般的な性質の証明もビルド対象です。検証例には動作確認用の仮の点数入力も含まれます。

## 入力・計算の扱い

- **外部の基準**：大臣指定の疾患・薬剤・施設基準、届出、患者条件、価格等は入力です。施設基準は現在、各モジュールの真偽値等で表し、基準本文・有効期間を持つ独立モジュールにはしていません。
- **履歴と同一性**：同一患者・医療機関・部位・採血・検査・一連・同時実施の識別と、日・月・年の算定履歴は呼出元で管理します。バッチ関数は扱う範囲内で履歴を共有しますが、全診療を横断する共通台帳は未実装です。
- **暦による期間**：「１月」「４月」「６月」「１年」等を30日・365日などに置き換えず、期間への該当と算定済み回数を入力します。
- **端数**：指定のない丸めはしません。モジュールにより1/2・1/5・1/10・1/100点単位又は非負有理数を用います。Ｄ５００・Ｅ３００の薬剤切上げは明記された式どおりです。
- **結果**：内訳・包括理由・未解決参照を区別します。`none` や０点の意味は各関数の定義に従います。包括対象外という結果だけでは、別算定可能とは判定しません。
- **接続**：検査・画像診断・投薬等の通則へ渡す関数があります。既存入力と接続先に同じ費用を二重計上しないことを前提とします。検証済みなのは記述したモデルの性質であり、点数表全体の網羅性・法令との完全一致を証明したものではありません。

### 計算上の選択と参照条件

現状の実装を確認・精緻化するときのため、次の選択を明示しています。

- 呼吸循環機能・超音波は年齢等の加算後に対象検査の90％を、ＣＴ・ＭＲＩは対象撮影の加算後に80％を適用します。ガス、フィルム、判断料・診断料等は各モデルで別に合算します。
- エックス線の通則２・３が重なる診断の50％は重ね掛けしません。入力順が第１の診断を定め、同一部位・時刻・方法の分割による枚数上限の回避は認めません。
- 同時撮影・同一アイソトープ等の主検査は、最高点を自動選択せず入力で指定します。
- 大腸ＣＴ加算は補足仕様に従い、64列以上を620点、16列以上64列未満を500点とします。
- ＰＥＴ等の算定施設要件と80％算定を決める基準は、別々の入力として扱います。
- 医学管理等の通則４〜６の感染対策関連加算は、今回の通則３の外来感染対策向上加算の算定を前提とします。
