医科点数表の構造と算定ロジックをLeanで段階的に形式化するプロジェクトです。

現時点では、点数表の大区分・対象項目の所属、初診料・再診料の同日併算定不可ルール、および初診料・再診料・外来診療料の点数と施設条件を定義しています。

- 通則
- 基本診療料
  - 初診料
  - 再診料
  - 外来診療料
- 特掲診療料
  - 処方箋料（投薬）

処方箋料は基本診療料ではなく、特掲診療料に属します。処方箋料の点数や算定要件は後続の段階で追加します。

同日併算定不可ルールは、同一患者の算定一覧に同じ日付の初診料と再診料が両方含まれることを禁止する制約として表現しています。

現時点の点数・施設条件（令和8年度として提示された値）:

- 初診料: 291点
- 再診料: 診療所、または200床未満の病院で76点
- 外来診療料: 200床以上の病院で77点
