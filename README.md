医科点数表の構造と算定ロジックをLeanで段階的に形式化するプロジェクトです。

現時点では、点数表の大区分・対象項目の所属、初・再診料の通則１〜３、同じ診療の別における初診料・再診料の同日併算定不可制約、および初診料・再診料・外来診療料の点数と施設条件を定義しています。

- 通則
- 基本診療料
  - 初診料
  - 再診料
  - 外来診療料
- 特掲診療料
  - 処方箋料（投薬）

処方箋料は基本診療料ではなく、特掲診療料に属します。Ｆ４００の区分１〜３（20・32・60点）、注１〜８の算定条件、減算・加算を `PrescriptionFee` 名前空間で定義しています。大臣指定の薬剤・疾患・施設基準など本文にない詳細は入力条件とし、月内算定済回数は呼出元で管理します。40％適用時の端数は丸めず、`Points.fifths`（1/5点単位）で保持します。

初・再診料の通則１〜３は `ConsultationGeneralRules` 名前空間で定義しています。

- 同時に複数傷病を診療しても原則１回とし、Ａ０００注５ただし書・Ａ００１注３・Ａ００２注５の例外は参照先の仕様に委ねます。
- 歯科・歯科以外の診療は独立に評価します。歯科の点数は医科の点数で代用しません。
- 入院中（短期滞在手術等基本料の算定患者を含む）の再診基本費用は第２部第１・３・４節に包括し、Ａ００１注５・６、Ａ００２注８・９の加算は包括から除外します。除外だけで算定可能とは判定せず、個別要件は参照先に委ねます。

従来の同日併算定不可制約は、同一患者・同じ診療の別について検査します。これは今回の通則１〜３から導出した規則ではありません。同時診療のまとまりと同日は区別しています。

現時点の点数・施設条件（令和8年度として提示された値）:

- 初診料: 291点
- 再診料: 診療所、または一般病床200床未満の病院で76点（許可病床総数とは区別）
- 外来診療料: 一般病床200床以上の病院で77点（情報通信機器を用いる場合は76点）

Ａ０００の注１〜16は [Sanri/InitialConsultation.lean](./Sanri/InitialConsultation.lean) の `InitialConsultation` 名前空間に定義しています。`assess` は基本点数と加算の内訳、`points` は合計点数を返します。`pointsAt` は注を適用する前の基本点数です。

- 対面・情報通信、注２〜４の減額、注５の継続診療と２つ目の診療科を判定します。２つ目の診療科には注６〜16の加算を付けません。
- 許可病床数と一般病床数を区別し、施設の種別・届出・患者条件を入力します。
- 注６〜９の年齢・時刻・休日・表示診療時間と加算の重複制限を判定します。時刻は午前０時からの分数、大臣指定の時間帯への該当は入力です。
- 注10〜16の加算と個別の月１回制限、注16とＡ００１注11の併算定禁止を判定します。月内算定済回数は呼出元で管理します。

参照先で定める施設基準等の詳細は補わず、本文の要件を満たすかを入力します。`generalRuleExceptions` は注５ただし書の判定を通則１の例外入力へ接続します。病床数・年齢・時刻の境界と各制限の検証例をLeanで確認しています。


Ａ００１の注１〜20は [Sanri/RevisitConsultation.lean](./Sanri/RevisitConsultation.lean) の `RevisitConsultation` 名前空間に定義しています。`assess` は別算定する基本点数・加算と、入院費用に包括される内訳を分けて返します。`points` は別算定分の合計です（包括のみの場合は `some 0`、対象外や併算定違反は `none`）。

- 注１の一般病床200床未満と、注２の許可病床総数200床以上を区別します。基礎モデルにも `Facility.hospitalWithGeneralBeds` を追加しました。従来の `Facility.hospital n` は全病床が一般病床である病院の略記です。Ａ００２の施設条件も一般病床数で判定します。
- 通常・届出済み情報通信・電話等の再診を区別します。２つ目の診療科では注３の加算除外、電話等では注９の加算除外を適用します。`generalRuleExceptions` は通則１の例外入力へ接続します。
- 外来管理加算の対象外行為、地域包括診療加算の同意・患者区分、データ提出、薬剤適正使用連携の要件を判定します。薬剤適正使用連携の暦月による情報受領期限と３月に１回の制限期間内の算定回数は入力です。
- 感染対策関連などの月１回制限、明細書発行体制等加算と電子的診療情報連携体制整備加算の併算定禁止、看護師等遠隔診療補助加算を判定します。明細書と電子的情報連携の加算は請求選択を入力できます。
- 通則３に従い、入院中・短期滞在手術等基本料の算定患者では注５・６の時間帯加算のみ別算定します。

処方箋料の区分２に使う地域包括診療加算の算定有無は、`claimsRegionalComprehensiveCare` から参照できます。月１回の回数入力は、初診・再診などで共通して制限される加算について呼出元で集約します。


Ａ００２の注１〜11は [Sanri/OutpatientConsultation.lean](./Sanri/OutpatientConsultation.lean) の `OutpatientConsultation` 名前空間に定義しています。`assess` は基本点数・加算と入院費用に包括される内訳を分け、`points` は別算定分の合計を返します。

- 一般病床200床以上の対象条件、対面77点・届出済み情報通信76点、注２〜４の57点への置換、２つ目の診療科の39点・29点を判定します。
- 注６の検査・処置は `Service` で表現し、`includedByNote6` で包括対象かを判定します。糞便カルプロテクチン、Ｄ００５の指定された５種類の除外、創傷・皮膚科軟膏処置の面積条件を区別します。面積は平方センチメートルの非負有理数で保持します。包括対象外という結果だけで別算定可能とは判定しません。
- 注６ただし書の検体検査実施料通則３の加算は、当該通則の要件と点数を入力します。２つ目の診療科ではこの加算と注７〜11の加算を除外しますが、注６本文の包括は維持します。
- 乳幼児・時間帯加算、電子的診療情報連携体制整備加算の月１回制限、看護師等遠隔診療補助加算を判定します。入院中・短期滞在では通則３に従い注８・９のみ別算定します。

`generalRuleExceptions` は通則１の注５の例外、`note2Or3Applies` は処方箋料注２で参照する減額条件に接続できます。施設の境界・面積・検査の除外・点数の置換・加算制限を検証し、Ａ００１とＡ００２の施設対象条件が相補的であることも証明しています。
