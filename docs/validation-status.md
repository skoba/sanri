## 再現

公式データを配布せず、次の検証はローカル資料なしで実行できる。

```sh
lake build
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests
```

実データとの限定照合は、利用条件を確認してローカルに資料を取得した環境で実行する。[tensuhyo/README.md](../tensuhyo/README.md) のコマンドは、本文上限・コード対応を呼出元が明示する。出典行を含む報告は `tensuhyo/audits/` に保存し、Git管理外とする。

### 事例の射影と登録版の接続

`lake env lean` で定理が使う公開定数をJSONへ評価し、Pythonが登録版CSV・マスターとローカルのコード対応から作った同じ射影と比較した。2026-10-22の糖代謝の同月背反・回数、D402の年齢区間と加算参照、D001(3)のコード別回数、D006(8)イ、D014(7)イの収載と欠落、D015(4)イ、D001(4)イ・D012(31)イ・(43)イ・D023(37)ウの欠落、D011(4)ウの収載の13件が一致。従来の18コード対は背反4表と包括表のいずれも基準日有効の関連行がなかった。新たなD004-2(7)の12対は群別監査の結果で、Leanの事例射影13件の範囲には含まれない。

ローカルで機械検査した等しさは登録版の射影と公開定数の間に成立する。Leanはその定数を意味付けした規則について定理を検査する。コード対応、CSVパーサー、通知の解釈、表の特例の発動条件はLeanの証明範囲外。[接続の設計](../DESIGN.md#文書の規則とマスターの照合)・[再生成手順](../tensuhyo/README.md#検体検査の外部照合を再生成する)
