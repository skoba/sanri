## 再現

公式データを配布せず、次の検証はローカル資料なしで実行できる。

```sh
lake build
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests
```

実データとの限定照合は、利用条件を確認してローカルに資料を取得した環境で実行する。[tensuhyo/README.md](../tensuhyo/README.md) のコマンドは、本文上限・コード対応を呼出元が明示する。出典行を含む報告は `tensuhyo/audits/` に保存し、Git管理外とする。

## 完成に向けて残っている作業

1. 対象版について、本文の各条項と既存Lean定義を対応付け、実装上の選択・外部判断・未形式化を分類する。
2. 各区分の通知、疑義解釈、訂正・廃止資料を探索し、資料の追加と解釈の改訂を区別する。
3. 同一の入力・対象結果を固定した上で、存在・一意性・競合を区分ごとに検証する。
4. 診療行為マスターを取得し、点数・コード対応を照合する。電子表との比較範囲を拡張する。
5. Python取込とLean側の意味付けの対応を検証し、実データの限定照合を証明へ接続する。
6. 未実装の外来区分、入院等を形式化する。既存研究との比較、原文翻訳のレビュー方法、研究結果の再現性を整理する。
