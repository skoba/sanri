# 公費負担医療の形式化計画

対象は医療情報基盤・診療報酬審査支払機構の制度別解説14回に掲げられた法別番号19種と、総論2回が扱う保険給付・高額療養費との調整である。2026年11月26日に掲載範囲と下記の公的資料の入口を確認した。各解説は2020〜2022年の発行当時のものなので、最初の検証日を2026年10月22日とし、その日に効力のある法律・政省令・通知・事業要綱を給付別に照合する。19番号はすべてLean形式化前である。[機構の掲載一覧](https://www.hpdx.or.jp/about/kohoshi/kouhosi_kouhi.html)・[既存の調査状況](source-register.md#公費負担医療の調査資料)

## 法別番号別の残作業

「検証する場面」はモデルの入力を変える合成例の候補である。施設指定、対象疾病、給付の始期・終期、保険との調整、自己負担額の決定方法は制度ごとに根拠を採録する。全国制度を自治体が実施する場合もその国の規定を扱い、自治体独自の上乗せは範囲外とする。

## 実装順と完了条件

1. **対象費用と履歴を定める。** 医科点数の算定結果から、患者・診療日・機関・対象疾病・費目ごとに保険診療費を受け取る。点から円への換算と端数処理に根拠を付け、保険給付額、公費ごとの給付額、患者の負担額を円で表す。入院時食事・生活療養など別の負担規則を持つ費目を保持する。機関をまたぐ月内累計、認定期間、保険資格、世帯区分は分けて入力する。
2. **54で上限を一例通す。** 対象費目だけの事例から始め、上限の直前・到達・到達後、暦月をまたぐ日、対象外の診療の混在、他機関分の累計不明を試す。たとえば「仮の上限5,000円、対象となる既払い4,200円、今回の上限適用前負担1,600円」という合成例で、今回の対象分の負担が800円となる条件を記述する。実際の上限階層・丸め・他給付との関係は適用版で確定する。[上限額の管理][rare-cap]
3. **外来から適用条件を広げる。** 10、15、16、21、38、52を追加する。15・16・21の共通規定を一度形式化し、対象となる医療を給付別に検査する。同じ工程で18・19は疾病別の対象費用と保険給付との関係、53は措置別の資格と費用範囲、12は保護決定と他法給付後の扶助額を、それぞれ個別給付として形式化する。まず他給付の結果を既知とした外来例で負担額を検証し、入院費目を工程4、複数給付間の配分を工程5で接続する。公費単独例、保険併用例、対象疾病と他疾病が混在する例をそれぞれ該当制度で再現する。
4. **入院・施設利用に接続する。** 入退院・措置・入退所の期間と対象費目を受け取れる段階で11、17、20、23、24、28、29、79の両給付を追加する。医科側で入院料、DPC、食事等をモデル化した範囲から接続し、対象費用を仮定した単体定理と費用算定から通した定理を区別する。
5. **複数制度が重なる場合を検証する。** 同じ費目に二つの給付が及ぶ組合せ、保険給付・高額療養費が変わる組合せを列挙し、それぞれを「根拠確認済み」「適用対象が交わらないことを確認」「根拠または事実の確認待ち」で記録する。給付順の根拠を条文単位で示し、受給者証の番号や公費欄の記載順を給付順に読み替えない。高額療養費は対象診療日の年齢・所得、集計単位、世帯合算、多数回該当、適用期間の改正、現物給付と事後償還が結果に影響する条件を確認する。[厚労省の高額療養費制度案内][highcost]

各給付の完了条件は、適用版の出典と条項、対象・対象外費目、実施または認定主体、負担者、集計単位と上限、他給付との調整を記録し、該当例と境界例をLeanで検査できることである。入力と結果型を明示したうえで、費目ごとの非負性、重複給付の排除、保険・公費・患者の最終負担額の合計が対象費用に等しいことを検証する。前提がそろえば結果の存在・一意性を調べる。認定・履歴・自治体の決定額等が不明なら未確定の入力と決定可能な範囲を残す。各給付単独での到達点と組合せごとの到達点を[検証状況](validation-status.md)に記録する。
