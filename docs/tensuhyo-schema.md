## 識別子と期間

- 診療行為コードは9桁の数字列です。`111000110`のようなコードを、告示の区分番号`A000`などと区別します。名称の一致だけで同一項目と決めず、将来取り込むマスターの対応情報を用います。
- 包括グループ番号は英数7桁の別識別子です。告示番号に似た構造ですが、複数の親が同じグループを参照する場合があり、診療行為や告示区分の一意な識別子にはなりません。入院グループ番号は`001`のような3桁で、`000`は関連なしです。
- 変更区分は`0`異動なし、`1`抹消、`3`新規、`5`変更、`9`廃止です。行の異動情報なので、`0`だけを読み込む設計にはしません。全件版と差分版の更新手順を混同しないよう、配布単位も保持します。
- 新設年月日はレコード情報の新設日です。廃止年月日は使用可能な最終日で、その日を含みます。`99999999`は廃止なしを表す番兵値で、通常の日付として解析しません。配布日・取得日とも区別します。
- 現版の廃止年月日は全行`99999999`ですが、補助マスターには新設年月日`20270601`の行が298件あります。収録されていても診療日時点で使用可能とは限りません。単一版の新設・廃止日だけから、過去の規則や点数を復元することもできません。

## 列配置

列番号は手引きと同じ**1始まり**です。予備列も含めて列数を検証し、空欄と`0`を勝手に同一化しません。

### 01 補助マスターテーブル（27列）

| 列 | 内容 |
| --- | --- |
| 1〜3 | 変更区分、診療行為コード、診療行為省略名称 |
| 4〜5 | 包括単位①、グループ番号① |
| 6〜7 | 包括単位②、グループ番号② |
| 8〜9 | 包括単位③、グループ番号③ |
| 10〜13 | 背反関連識別：1日、同一月内、同時、1週間 |
| 14〜19 | 予備（17列目は空欄、ほかは`0`） |
| 20 | 入院基本料識別（参照先グループ番号） |
| 21 | 算定回数関連 |
| 22〜25 | 予備 |
| 26〜27 | 新設年月日、廃止年月日 |

背反・算定回数の関連識別は`0`関連なし、`1`関連ありです。包括単位は`0`関連なし、`1`1日、`2`同一月内、`3`同時、`5`手術前1週間、`6`1手術です。手引きでは最大2桁の数値として表記され、現CSVは`1`などの表記です。

### 02 包括テーブル（7列）

| 列 | 内容 |
| --- | --- |
| 1〜4 | 変更区分、グループ番号、診療行為コード、診療行為省略名称 |
| 5 | 特例条件 |
| 6〜7 | 新設年月日、廃止年月日 |

補助マスターで親が参照するグループに、このテーブルの子を結び付けます。期間の範囲は親の包括単位から取得し、親子両方の行の期間を考慮します。グループ内を相互に包括すると解釈しません。

### 03-1〜03-4 背反テーブル（各10列）

| 列 | 内容 |
| --- | --- |
| 1 | 変更区分 |
| 2〜3 | 診療行為コード①、診療行為省略名称① |
| 4〜5 | 診療行為コード②、診療行為省略名称② |
| 6 | 背反区分 |
| 7 | 特例条件 |
| 8 | 予備 |
| 9〜10 | 新設年月日、廃止年月日 |

時間の範囲はファイルごとに異なり、テーブル1は1日、2は同一月内、3は同時、4は1週間です。背反区分は`1`①を算定、`2`②を算定、`3`いずれか一方を算定です。`3`から高点数優先などの選択規則は導けません。

現版には、コード①②と優先方向を反転させた行がすべて存在します。照合結果を二重に数えないようにしつつ、単純にコード対をソートして優先方向を失わないようにします。

### 04 入院基本料テーブル（8列）

| 列 | 内容 |
| --- | --- |
| 1〜4 | 変更区分、グループ番号、診療行為コード、診療行為省略名称 |
| 5 | 加算識別 |
| 6 | 予備 |
| 7〜8 | 新設年月日、廃止年月日 |

補助マスターの入院基本料識別から参照する、加算候補のテーブルです。同一グループで加算識別が等しい加算同士は併算定できません（手引き17〜18頁）。関連があるだけで施設基準や患者条件の充足まで意味するわけではありません。

### 05 算定回数テーブル（14列）

| 列 | 内容 |
| --- | --- |
| 1〜3 | 変更区分、診療行為コード、診療行為省略名称 |
| 4〜5 | 算定単位コード、算定単位名称 |
| 6 | 算定回数（単位ごとの上限） |
| 7 | 特例条件 |
| 8〜12 | 予備 |
| 13〜14 | 新設年月日、廃止年月日 |

単位には日`121`、月`131`、週`138`、一連`141`、初診時`159`などがあります。現版は5,249コードに6,350行あり、1,100コードに複数行があります。コードをキーとする単一行の辞書にはせず、同じコードの日上限・月上限などを保持します。月・一連・疾患・臓器などの範囲には、それぞれに対応する診療履歴や識別情報が必要です。

## 条件を判定するときの限界

包括・背反・回数の特例条件は`0`条件なし、`1`条件ありですが、`1`の行には具体的な条件式は入りません。告示・通知を参照する追加規則が必要です。`0`も、その行の関係について特例が設定されていないという意味であり、診療行為全体の算定条件を満たす証明にはなりません。

手引き20〜24頁には、テーブルへ設定しない包括、傷病名・部位等に限定される背反、3項目以上が絡む制限などが説明されています。行がない場合を「併算定可能」「回数無制限」と確定せず、確認対象の規則が網羅されているかを区別します。また、手引きの事例は令和2年度の点数表に基づくため、例示点数を令和8年度のデータとして取り込みません。

現8ファイルの全診療行為コードが補助マスターに存在することを確認しました。これはスナップショット内の参照整合性の確認であり、告示に対する規則の完全性や、Sanriの既存定義との一致を確認したものではありません。
