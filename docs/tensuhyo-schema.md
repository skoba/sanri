## 識別子と期間

- 診療行為コードは9桁の数字列です。`111000110`のようなコードを、告示の区分番号`A000`などと区別します。名称の一致だけで同一項目と決めず、将来取り込むマスターの対応情報を用います。
- 包括グループ番号は英数7桁の別識別子です。告示番号に似た構造ですが、複数の親が同じグループを参照する場合があり、診療行為や告示区分の一意な識別子にはなりません。入院グループ番号は`001`のような3桁で、`000`は関連なしです。
- 変更区分は`0`異動なし、`1`抹消、`3`新規、`5`変更、`9`廃止です。行の異動情報なので、`0`だけを読み込む設計にはしません。全件版と差分版の更新手順を混同しないよう、配布単位も保持します。
- 新設年月日はレコード情報の新設日です。廃止年月日は使用可能な最終日で、その日を含みます。`99999999`は廃止なしを表す番兵値で、通常の日付として解析しません。配布日・取得日とも区別します。
- 現版の廃止年月日は全行`99999999`ですが、補助マスターには新設年月日`20270601`の行が298件あります。収録されていても診療日時点で使用可能とは限りません。単一版の新設・廃止日だけから、過去の規則や点数を復元することもできません。

## 条件を判定するときの限界

包括・背反・回数の特例条件は`0`条件なし、`1`条件ありですが、`1`の行には具体的な条件式は入りません。告示・通知を参照する追加規則が必要です。`0`も、その行の関係について特例が設定されていないという意味であり、診療行為全体の算定条件を満たす証明にはなりません。

手引き20〜24頁には、テーブルへ設定しない包括、傷病名・部位等に限定される背反、3項目以上が絡む制限などが説明されています。行がない場合を「併算定可能」「回数無制限」と確定せず、確認対象の規則が網羅されているかを区別します。また、手引きの事例は令和2年度の点数表に基づくため、例示点数を令和8年度のデータとして取り込みません。

現8ファイルの全診療行為コードが補助マスターに存在することを確認しました。これはスナップショット内の参照整合性の確認であり、告示に対する規則の完全性や、Sanriの既存定義との一致を確認したものではありません。

## 医科診療行為マスター

対象は、[医科診療行為マスターの配布ページ](https://www.hpdx.or.jp/seikyushiharai/tensuhyo/kihonmasta/kihonmasta_01.html)の令和8年度版・2026年11月2日公開の全件ファイルです。ローカル資料の配置先は `tensuhyo/master/2026-11-02/` で、Git管理・公開リポジトリには含めません。列の意味は[マスターファイル仕様説明書・令和8年度版](https://www.hpdx.or.jp/seikyushiharai/tensuhyo/kihonmasta/index.html)（2026年11月12日版）の本編PDF 31〜49頁、別紙7-12（別紙PDF 91頁）、ファイルレイアウトPDF 11〜14頁と照合しました。頁はPDFの先頭を1頁とした番号です。確認したのは下表の列で、全150列ではありません。

全件ファイルはZIP内の1本のCSVで、11,837行・150列、CP932・CRLF・ヘッダーなしです。[取込ツール](../tools/procedure_master.py)は、登録したZIPのSHA-256、列数、下表の列の形式と列挙値、日付、診療行為コードの重複を検査してから読みます。

### 区分番号との対応

- 区分は列85・92・93から `D007`、`D006-4` の形に組み立てます。枝番は第1階層までで、`B001-2-7` のような第2階層の枝番号は区分欄に現れません（別紙7-12）。該当する区分は、第1階層までの欄と項番から個別に対応付けます。
- 項番は告示の項に対応します。項のない区分は項番`0`です。注の加算が独自の項番を持つ区分があります。
- 準用項目は、準用元と同じ章・部・区分番号・項番を持ちます。通知で追加された検査は準用項目として現れるため、告示本文だけから作った項目表より行が多くなります。
- 検体を表すコードは区分番号`999`です。薬剤料・特定保険医療材料料・フィルム等の区分には行がありません。価格は医薬品マスター・特定器材マスターの対象です。

区分欄の一致は、名称によらない対応の手がかりです。項・注との対応、点数、算定条件は別に照合します。

### 期間

- 登録版の廃止年月日は全行`99999999`です。変更年月日が2027年6月1日の298行と2026年11月1日の2行は、2026年10月22日の診療には使えません。
- 基準日より後に変更された行の変更前の内容は、この版から復元できません。公開日より前の日付を基準にするときは、その間の改定分ファイルと内容説明で変更を確認します。登録版では2026年11月2日の改定分3件が該当します。
- 取込ツールは公開日より後の日付を基準にできません。後の変更が分からないためです。

- 基準日に使用可能な行は11,537行です。

## 本文・通知の位置索引

索引は登録版PDFの資料ID・版・URL・SHA-256・物理頁数を `source` に保持します。位置の `page` と `line` は1始まりです。行は `pdftotext -layout` で抽出した頁内の行で、空行も行番号に含みます。

| ファイル | 形式 |
| --- | --- |
| `fee-index.json` | 掲載区分の `items`・`notes` に番号と開始位置、`path` を付ける。注の `item` は属する項番又は `null`。無番号注は `number: null` とし、区分全体の無番号注は索引内で出現順に `note/unnumbered/<連番>` とする。カナの枝は注の `children` に記録する。`item_note_paths` は項・注の比較キー列。見出し・注の枝は分母に重ねて数えず、判定に疑義がある区分は `clause_issues` と `item_note_paths: null` で示す。空リストは項・注の見出しを検出しなかった区分を表す |
| `notice-index.json` | `blocks` は区分見出し。併記されたコードは `codes` に保持する。範囲表記は端点だけを記録し、問題として出力する。`general` は章・部・節・款の階層を持つ区分外のブロック。ブロック・段落・枝の `start` と `end` は両端を含む。`paragraphs` の `style` は括弧付き、通則の算用数字、無番号の別。`number: null` は無番号段落候補。`children` にア・イ等の枝と比較に使える `id_suffix` を持つ。番号の欠落・重複はブロック内の `issues` に記録する |
| `notice-ledger-check.json` | Lean通知IDの相異なるパスを区分・段落・枝で照合する。`matched`・`missing`・`ambiguous` は照合結果。出典の版・解釈の確認状態は別途管理する |
| `specimen-backlog.json` | 本文の階層で第2章第3部第1節と第4節のD400台を選び、削除表記を除く。項・注・親段落は同じIDがある場合に対応済みと数える。注・段落の枝に対応する参照は部分対応として列挙する。`source_backed_clauses` は索引に一致した見出し・項・注・通知・枝の相異なる参照数。通知未発見や抽出に疑義がある場合の残件数は `null`。集計は計数できる区分の小計 |

`notice-index.json` の `primary_only`・`notice_only` は掲載区分見出しの章・コード差、`notice_deleted` は通知の削除表記、`duplicate_codes` は重複した区分見出しです。トップレベルの `issues` は区分らしい行を区分見出しとして解析できなかった位置、`empty_pages` は文字のない頁を記録します。別添1の2・別表は `appendix_start` から後の対象外範囲です。索引は登録版の文字層と欄位置による機械抽出です。要件の網羅性、適用版、形式化の意味の一致は別のレビューを要します。

## 公開Leanモデルの条項ID

`Rule.id` は資料内の条項位置を示します。同じ条項に複数の制約を置けるため、規則の識別にはモジュール・定義名（リストでは0始まりの添字、列挙型を受ける定義では構成子も含む）を使います。版・資料ID・物理頁の記載・確認状態は `SourceRef` を参照します。

| 出典 | 書式 | 例 |
| --- | --- | --- |
| 本文の区分見出し | `primary/<区分>/heading` | `primary/D400/heading` |
| 本文の項・項内の注 | `primary/<区分>/item/<項>[/note[/<注番号>]]` | `primary/D005/item/6/note` |
| 本文の区分内の注 | `primary/<区分>/note/<注番号または記号>` | `primary/D007/note/ro` |
| 本文の通則 | `primary/ch<章>-part<部>[-section<節>][-subsection<款>]/general/<号>` | `primary/ch2-part3-section4/general/1` |
| 留意事項通知 | `notice/<区分>/paragraph/<号>[/<記号>]` | `notice/D007/paragraph/17/e` |
| 疑義解釈 | `clarification/<資料キー>/question/<問番号>` | `clarification/r08-20260323-01-medical/question/3` |
| 未分類・合成例 | `unclassified/<規則を説明する名前>` | `unclassified/outpatient-chemistry-composition` |

区分は告示の枝番号をハイフンで保ちます。番号や記号のない区分内の注は、本文位置索引と同じく出現順で `note/unnumbered/1` のように記載します。カナの枝は `a, i, u, e, o`、`i, ro, ha` のように原文の記号に対応する小文字で記載します。連続する項は `item/1..15` と書けます。出典が同種で複数位置に対応する場合は、完全なパスを `+` で連結します。資料キー `r08-20260323-01-medical` は令和8年3月23日事務連絡その1の医科部分です。

条項IDだけで機械的な結合ができるため、`SourceRef` の構造と既存の位置記述を維持します。複合制約の一部や引数で与える出典は未分類に残します。集計の条項数は参照パスの重複を除いた数で、本文・通知全体に対する完了率には、別途、完全な条項索引が必要です。[生成手順](../tensuhyo/README.md#条項台帳と点数照合を再生成する)
