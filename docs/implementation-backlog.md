# 令和8年医科点数表の区分別残作業と実装順

2026年11月26日の棚卸しでは、別表第一に「削除」と書かれていない番号付き区分が**2,401区分**ある。このうち**2,268区分は個別の計算モデルを新設する対象**、**133区分は既存の個別モデルを条項別に照合する対象**である。起点は令和8年厚生労働省告示第69号・別表第一の2026年10月22日取得版。特定の診療日に適用できるかは、訂正・施行日・経過措置を追って確定する。[医科点数表本文](https://www.mhlw.go.jp/content/12400000/001686842.pdf)・[資料台帳](source-register.md)

## 全区分一覧の開き方

手元の全件一覧は `tensuhyo/inventory/medical-backlog.tsv`。**「種別＝区分」で絞ると、全2,401区分を枝番号ごとに1行ずつ読める。** 章・部・節・款、区分番号、PDF見出しの先頭行、物理頁・抽出行、既存実装の状態、主なLeanファイル、着手工程、残作業が入っている。同じ番号の各項・注・検査種類は、その区分に属する次の作業単位とする。公費は別に全19番号の制度名、根拠資料、検証例を一覧にした。[公費法別番号別の計画](public-funding-plan.md)

原本を配置した環境で、次のコマンドから同じ一覧を再生成できる。PDFのSHA-256を検査し、本文の章・部・節・款の97見出しを目次と順番・表題まで照合する。1本目のJSONは出典・階層・削除の原表記を確認する索引、2本目のTSVはLeanとの対応を加えた作業一覧である。原文の抽出行を含む両方のファイルをGit管理外に置く。[原本の配置方法](../tensuhyo/README.md#本文pdfからlean草案を作る)

```sh
python3 -m tools.fee_inventory
python3 -m tools.fee_backlog
```

## どこに個別モデルが必要か

「個別モデルあり」は、その区分固有の計算を少なくとも一部記述したもの。「参照のみ」は、他区分の包括・加算・外部点数等との対応を特定したもの。「新規」は既存Leanとの個別対応を登録していないもの。包括先として名称が出てくるだけでも、その区分自体の要件・例外・点数は新たに記述する必要がある。[Leanとの区分対応](../tools/fee_coverage.py)・[条項ごとの検証状況](validation-status.md)

区分数は作業量を表さない。手術（K）は区分数の6割を占めるが、本文の分量では2割強で、注も通知もない区分が多い。入院料等、医学管理等、在宅医療は1区分あたりの本文と通知が長い。「個別モデルあり」の区分にも未着手の項や通知段落が残る。進捗は本文の項・注・ただし書と通知の段落を単位に数え、区分数は索引として併記する。分量の概算と数え方の変更は[研究計画](roadmap.md#現在地と組み直しの要点)に記した。

### 番号付き区分のほかに形式化するもの

| 対象 | 一覧の単位と残作業 |
| --- | --- |
| 上位規則 | 「通則」と明記された37見出しをTSVに収載。各号・ただし書と適用先の区分を結ぶ。「通則」という見出しのない共通規定や区分内の注も、該当する章・部・節・款・区分の本文から採録する |
| 第3章・介護老人保健施設入所者 | 章前文と、併設・非併設それぞれの4項を個別に収載。併設側は緊急時施設治療管理料、非併設側は施設入所者共同指導料を扱う。各部の残る3項は施設入所者自己腹膜灌流薬剤料、施設入所者材料料、その他の診療料。第1・2章の準用先と介護保険との給付調整を結ぶ |
| 第4章・経過措置 | 2項を個別に収載。A103精神病棟入院基本料に関する旧区分の適用と、精神科地域包括ケアに係る入院をA311-2で評価する際の期間通算を、旧版と入院履歴に結ぶ |
| 削除の来歴 | 単独削除90見出しと一括削除24見出しを原表記の単位で保存。「から…まで」の間に存在した枝番号や、「及び」で結ばれた番号の間の区分を補間しない。旧版が適用される患者の検証時に旧規定を取得する |
| 別告示・別表 | 施設基準・届出、指定疾患、薬価・材料価格、複数手術特例、DPC/PDPSの診断群分類・期間別点数・係数、入院時食事・生活療養、医療と介護の給付調整について、それぞれの適用版から独立の一覧を作る。今回の2,401という分母は別表第一の区分数である |

第3・4章は本文の物理399〜400頁にある。制度上の表記に従い、同じ番号の再掲・準用と独立区分を区別している。[別表第一の章末](https://www.mhlw.go.jp/content/12400000/001686842.pdf#page=399)

**公費は並行工程**とする。医科点数から対象費目ごとの円額を渡せる時点で、法別54の一患者・同月複数機関の例に着手する。入退院を要する給付は工程4以降に接続し、制度単独・複数公費・高額療養費の調整を別々に検証する。実装対象とする国の制度は機構の解説に掲載された19番号、地方単独助成は今回の対象外である。[番号別の作業・検証例・公式資料](public-funding-plan.md)・[機構の掲載索引](https://www.hpdx.or.jp/about/kohoshi/kouhosi_kouhi.html)

工程1と3aは並行して進め、制約の標準形と条項台帳が検体検査で動くまで3b以降の区分追加は始めない。TSVの「着手工程」欄は3a〜3cを「3 外来・在宅各部」としてまとめて表示する。番号別の残務は[検証状況の残務一覧](validation-status.md#残務一覧)にある。

区分の完了判定には、全条項・参照先の版と原文を照合し、独立した制約の翻訳レビューと、具体的な該当例・除外例・境界例の確認を要する。金額が決まるとされる条件では解の存在と一意性を検証する。選択が許される条件や医学的判断が未確定の例では、許される結果または必要な入力を記録する。欄ごとの条件は[研究計画の完了条件](roadmap.md#条項と区分の完了条件)に固定した。工程3aで条項あたりの作業量を実測してから、残る部の工数を見積もる。[全体計画と完成条件](roadmap.md)
