## 条項と区分の完了条件

区分を完了と数える条件を次のとおり固定する。各項目は条項台帳の別々の欄に記録し、一つの欄の完了で他の欄を代用しない。方式の根拠は[設計文書](../DESIGN.md)にある。工程3a〜3cで範囲を閉じる判定には1〜3、5、6を用いる。4のレビューは、対象全体を一通り形式化した後にまとめて行う。

1. **条項の列挙**　本文の項・枝・注・ただし書、適用される上位通則、通知の段落、対応する疑義解釈の問を条項IDで列挙する。入院に限る条項や対象外とした条項は、理由を付けて残す。
2. **独立した制約**　各条項を一つの `Rule` とし、`holds` から計算関数を呼ばない。項目の列挙や点数の対応表は共有してよい。未確認の事実は `Option` 等で表し、既定値で偽・0回としない。外部判断とした語は、その意味と根拠を入力の説明に書く。
3. **性質の証明**　入力の範囲を述語で示し、その全体で結果が存在して一意であること、又は許される結果の集合を証明する。範囲が空でないことを具体例で示す。計算関数がある場合は、制約に対する健全性と完全性を証明する。該当例・除外例・境界例を置く。
4. **レビュー**　実装者とは別の読み手が、原本と制約を条項ごとに突き合わせ、版・日付・読み手を記録する。レビュー前の条項は、台帳でレビュー済みと区別できる状態に保つ。
5. **関連資料**　通知・疑義解釈・訂正を索引で確認した範囲と日付を記録する。見つからなかったことを不存在と書かない。
6. **外部照合**　診療行為マスターのコード対応と点数、電子点数表の包括・背反・算定回数を、対象・日付・単位をそろえた射影で比較し、差を分類する。

## 何を数え、何を証明するか

- **条項の網羅**　対象版の有効条項を分母とする。単位は本文の項・注・ただし書と通知の段落で、区分数は索引として併記する。原文照合済み、形式化済み、翻訳レビュー済みの件数を個別に集計する。施設基準や別表等へ委ねた条件も追跡する。医学的判断を外部入力にする場合は入力の意味と根拠を記録し、未調査の要件は残件に数える。
- **規則の検証**　各領域で入力の範囲、許された選択、結果型、調べる性質を先に定める。対象となる具体例を示し、金額が決まるはずの範囲では解の存在と一意性をともに証明する。選択の余地がある規則では許容結果の集合を示す。既存の算定関数については、出典から独立に書いた制約との対応を検証する。
- **不一致の検討**　解が二つある場合は同一入力での二つの結果を、解がない場合は成立し得る入力と競合する条項を示す。本文のみ、通知を反映した読み、疑義解釈・訂正を反映した読みを比較し、適用日・例外・形式化を再確認する。
- **マスターとの比較**　電子点数表、別配布の診療行為マスター、DPC電子点数表は用途ごとに版を固定する。本文から形式化した制約と、コード・期間・単位を合わせた表の規則について、期待する同値または片方向の包含を調べる。CSV読込からLean入力までの対応も検証項目に置く。原本・変換データ・実データ入りの報告はローカルの `tensuhyo/` で管理する。

全体系のモデル完成は、対象とした資料・期間の全有効条項について、原文と対応する定義・参照がレビュー済みになった時点とする。検証の到達点は別に、予定した性質を分母に、証明済み・反例確認済み・未解決の件数と適用範囲で公表する。資料が足りない箇所や未解決の参照がある場合は、その範囲を明示して部分成果を公開する。

## 公費負担医療の対象と検証

機構の掲載一覧（2026-11-26確認）を研究対象の索引とする。制度別14回に記載された法別番号は重複を除いて19種。自立支援医療は2回にわたり、法別79には二つの給付がある。別掲の「制度の概要」「高額療養費」も横断課題に含める。現在の到達点は対象を特定した段階である。記事は2020〜2022年の発行時点の解説であり、令和8年の診療に適用する条項は制度ごとに法令・通知・事業実施要綱の適用版で確認する。[機構の掲載一覧](https://www.hpdx.or.jp/about/kohoshi/kouhosi_kouhi.html)

| 調査する分野 | 一覧から追跡する給付と法別番号 |
| --- | --- |
| 感染症と肝炎 | 結核の適正医療10・入院医療11、感染症の入院医療28・新感染症29、B型・C型肝炎治療38 |
| 障害・精神 | 更生医療15・育成医療16・精神通院医療21、療養介護医療24、精神科措置入院20 |
| 児童・母子 | 療育の給付17、肢体不自由児通所医療・障害児入所医療79、小児慢性特定疾病52、児童福祉法の措置等53、未熟児の養育医療23 |
| 難病・被爆者・生活保護 | 特定医療費54、被爆者の認定疾病医療18・一般疾病医療19、医療扶助12 |

全国制度のうち自治体が実施・認定するものも調べる。たとえば法別38の実施主体は都道府県であり、国の事業が助成対象とする治療と費用を特定できる。受給認定と有効期間は個別の入力とし、地方単独助成・独自上乗せは収集対象外とする。個別自治体の定めを要する額や未確認の他給付は未解決と記録する。[厚生労働省・肝炎治療特別促進事業](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/kekkaku-kansenshou/kanen/kangan/iryouhijyosei_00006.html)

最初は法別54の月上限を扱う。対象となる診療と指定医療機関、認定期間、同一患者の同月累計を固定し、他院・薬局も含む対象負担の増分を求める。次に、同じ受診に対象外の診療がある例、医療保険との併用、公費単独、複数公費、高額療養費との調整を各制度の根拠に沿って検証する。法別番号の数値順から給付の優先順位を推定しない。[難病法5条・12条](https://www.mhlw.go.jp/web/t_doc?dataId=80ab4067)、[厚生労働省・自己負担上限額の管理](https://www.mhlw.go.jp/content/10900000/0000062668.pdf)

公費の網羅性は医科点数表の条項数と別に数える。各給付について適用条項、対象費用、負担者、上限・履歴単位、他給付との調整を対応付け、根拠を確認した条件で負担額の合計が対象費用と一致するかを調べる。制度によって要件や優先関係が異なるため、制度単独の検証済み範囲と、組合せごとの検証済み範囲をそれぞれ示す。

公費は、工程3bで外来の費目別点数を出典付きの制約から渡せるようになった時点で、法別54の一例に着手する。入退院を要する給付は工程4以降に接続する。[公費19番号の実装順](public-funding-plan.md)
