## 施設基準・結果・点数単位

| 既存モデル | 属性・基準・適合・届出・有効期間の表現 | 結果・点数単位 |
| --- | --- | --- |
| D005 | ESRの院内実施、委託、報告は実施上の事実。施設基準の適合・届出・有効期間の型はない | `Assessment` が算定・要件不成立・未確定を区別。閉世界の点数射影に0点があり、A002包括は別の判定。整数点 |
| D007共通項目型 | 検査項目の識別を担う | 点数・結果型は各評価器が持つ |
| D007前半 | 測定法とマンガンの患者・栄養条件。施設基準の入力はない | `Option (List Item)`・`Option Nat`。情報不足、未対応の反復、不適切な選択に `none` を共用。包括は選択後の項目リストに整数点の一括点数を適用 |
| D007中前半・中後半 | 血液ガスの院内実施、学会指針等は外部確認。施設基準の適合・届出・有効期間の型はない | `Assessment` が算定・要件不成立・選択競合・未確定を区別。準用や併施の選択は別の関係。整数点 |
| D007後半 | `GasSite` と病床の有無、院内委託、連携先、緊急・報告の条件。施設基準の適合・届出・有効期間の型はない | `Assessment` の算定・要件不成立・未確定、ガスの構成測定・準用の包括は別の関係。整数点 |
| 糖代謝 | 患者の例外該当を外部から受ける | 算定選択の確定・不適切・未確定を区別。点数射影の `none` は後二者をまとめる。整数点 |
| D026 | 保険医療機関属性、管理加算区分、基準の届出を表す真偽値。基準本文、適合確認、届出効力期間の独立した表現はない | `Option Assessment`。外来の対応外の条件等で `none`。内訳内の0点は既算定・包括等を含む。整数点 |
| 外来血液検査・D400 | 一保険医療機関の限定事例。採取の既存入力には機関属性、別の採取項目用の施設基準届出フラグがある | `Option Breakdown` と整数点。採取の `NotSeparateReason` は包括・回路採血・同日既算定等を区別。事例の点数射影には0点もある |
| 残尿測定 | 一機関を事例の範囲とする。施設基準の入力はない | 回数・同日関係の `Prop`。点数の結果型は持たない |
| 届出の疑義解釈 | 固定日での旧届出、基準日以降の新加算の意図、別途届出の事実。適合や受理・効力期間は別課題 | `FilingRequirement` と `FilingPartMet`。点数は持たない |

次回は施設IDに属性の期間、基準の版と適用期間、基準適合の証拠、届出の種別・受理・効力期間をそれぞれ結び、条項が要求する事実だけを診療日時点で参照する。結果型は算定点数（0点を含む）、包括とその参照先、要件不成立、確認不足、未対応を区別できる形を候補とし、既存の射影が返す意味を個別に証明する。点数単位は初めに整数点との対応を固定し、分数を要する区分では非負有理数として扱い、丸めと換算は根拠条項に置く。
